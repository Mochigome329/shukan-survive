# 週刊サバイブ

週刊連載を持つ漫画家となり、毎週「今週の話」を展開カードの組み合わせで作るデッキ構築型スコアアタック。
読者アンケートのノルマを超え続け、全25話の最終回まで生き残るのが目的。

ビルドすると単一HTMLファイル `dist/uchikiri.html` が生成され、スマートフォンや PC のブラウザで開くだけで動作する。
外部リソースを一切参照しないので、ファイル1つを配るだけで遊べる。

**実装範囲: 第1〜25話（最終回まで）／ v1.0**

## 遊びかた

- キャストの人気度 × 展開カードの話題性 ＝ その週のスコア
- スコアがノルマに届かないと打ち切り警告が1つ増え、3つで連載終了
- カードの組み合わせが噛み合うと**役**が成立してカットインが入り、大きく加点される（全100種）
- 第8・16・24話は**ボス週**。ノルマ未達で警告に関係なく即打ち切り
- 第25話が最終回。これまでの連載内容によって選べる**結末**が変わる

## 使い方

```bash
npm install
npm run build
```

| コマンド | 内容 |
|---|---|
| `npm run dev` | 開発サーバ（Vite） |
| `npm run build` | 型検査 → ビルド → 配布物検査 |
| `npm run typecheck` | 型検査のみ |
| `npm test` | コアロジックの単体テスト（vitest / 382件） |
| `npm run sim` | シミュレーター。`npm run sim -- --runs 500 --weeks 8`（25話フルは重い） |
| `npm run cards` | 全カード・全役の一覧HTMLを `reference/cards.html` に生成（絞り込み検索つき） |
| `npm run cards:apply` | 一覧HTMLで編集したフレーバーテキストを `cards.json` に反映 |

## 構成

```
src/
  data/    cards.json / quotas.json / tutorial.json（Zod検証つき）
  core/    types / rng / scoring / combos / demands / run / shop / finale /
           storyTypes / chronicle / search / validate（純関数+テスト）
  sim/     simulator.ts（UIなしで多数ランを実行）
  state/   gameReducer.ts（title→setup→play→result→shop のフェーズマシン）
  ui/      画面コンポーネント（役カットイン・描き文字・効果音・連載年表を含む）
  assets/  タイトル画（webp）
```

- コアロジックはUI非依存の純関数。確定前プレビューとリザルトは同じ `computeScore` を使う
- 乱数はシード注入可能（mulberry32）で、draw / redraw / shop / boss の用途別に系列を分離
- 役の定義は `src/core/combos.ts` のレジストリが唯一の正（100種）
- 効果音は音声ファイルを持たず Web Audio API で合成する（`ui/audio.ts`）
- 漫画の描き文字は画像ではなくSVGパス（`scripts/trace-sfx.mjs` が生成、`data/sfx.json`）

## 素材について

- タイトル画（`src/assets/title-art.webp`）と描き文字13点は画像生成AIで作成したもの
- 効果音はすべてコードによる合成音で、音源ファイルは使用していない
- フォントは端末のシステムフォント（Hiragino Kaku Gothic ProN / Yu Gothic / Noto Sans JP）
