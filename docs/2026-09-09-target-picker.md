# 対象選択とオノマトペの改善

対象指定カードを手札から選ぶと、直ちに対象選択ダイアログを開く。候補が1人でも明示的に選ぶ。修行・覚醒・復活・登場などの候補は既存の対象解決処理を共有し、同じ原稿で登場したキャラも対象にできる。陣営指定が必要なら同じダイアログで続ける。キャンセルはカードを手札へ戻し、対象・陣営指定も解除する。

候補は顔、名前、現在陣営、基礎人気と恒久加算、居場所で表示。手札には「対象を選ぶ」を表示。スマホは2列、本文スクロール、戻す操作を上部に固定。native dialogで背面操作を抑制し、Escapeと閉じた後のフォーカス復帰を実装。

役成立のオノマトペを拡大。衝撃系を強くし、情緒系は控えめにした。絵のコマ内に収め、役名・効果の領域と分離。自動演出時間は変更していない。

検証: 対象選択のreducerテスト12件、ダイアログSSR4件を追加。全638件を実行し、旧仕様期待のv63を更新・再実行した結果637件成功相当。残るshapesの生成器テストは既存の子プロセス起動EPERM。型検査・Vite本番ビルド・単一HTML外部参照検査成功。別担当のソースレビューで重大所見なし。ブラウザ操作は以前拒否され、再許可の回答がないため未実施。
