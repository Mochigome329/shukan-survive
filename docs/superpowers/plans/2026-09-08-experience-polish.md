# 週刊サバイブ：体験と誌面の改善

ユーザー承認：提案1〜3を実装し、ビジュアルも改善する（2026-09-08）。

## 方針

紙・墨・朱のコミック表現を維持。操作対象の太枠と押下時のハード影を残し、全面網点・角丸の混在・装飾の多さを整理する。既存CSSを直接整理し、別のCSSフレームワークは追加しない。design-style-refsのGT Americaから文字サイズによる階層と6px刻みの余白を参照。既存の作風を優先するため、同辞書の影禁止とウェイト400固定は適用しない。

## 実装と受け入れ

- [ ] 仕込みヒント：純関数で伏線回収・緊張解放・無料再登場を導出。手札とショップに文脈を表示。未発見の役の条件は教えず、成立していない効果を断言しない。空状態・回収カード不在・復活対象不在・最終回をテスト。
- [ ] 操作ガイド：第1話だけバトルと修行を手札に保証し、実際の選択・対象指定に反応する非モーダルの短い案内に置換。スキップ可。通常開始・再開では手札保証なし。編集会議の説明は非モーダルで一段に。選択解除・スキップ・通常ラン不変をテスト。
- [ ] 演出：初発見と仕込み回収をカットインにし、既知の通常役はまとめて表示。全役の明細と発見登録は維持。早送り・音量復帰・最終回ボーナスの流れを維持。選別の純関数をテスト。
- [ ] 誌面：タイトルの画像は維持し、雑誌の見出し・柱・帯の構造で配置。カードの名前・数値・状態を整列、操作ボタンの角を統一。プレイ・ショップ・結果・セットアップ・図鑑を同じ紙面表現で統一。モーション軽減とフォーカス表示を整える。
- [ ] 型検査、全単体テスト、単一HTMLビルド、差分レビュー。

## 制約・検証記録

React / TypeScript / 既存CSSのみ。ゲームの得点ルール・ノルマ・保存形式は変えない。新規サービス・認証・外部フォント読み込みなし。変更は未コミットの専用ブランチでレビュー可能にする。

ブラウザでlocalhostを開く操作が承認レビューに拒否されたため、画面取得を別経路で試みない。実機の見た目・操作確認は未検証として明記する。

標準Vite設定読込とVitestのforkは環境のspawn EPERMで失敗。native config loaderとthreads poolで実行する。ベースラインのshapes生成器子プロセステストも同制約を受ける。
